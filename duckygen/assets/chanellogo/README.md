# Sample channel logo

`log.png` is a transparent PNG sample channel mark: an original duck/circuit design in Duckygen's charcoal, coral, paper and green palette. Generated with the built-in image tool on November 1, 2026. It is text-free and is not an existing company's logo or a finalized channel identity.

Asset ID: `logos/channel-sample`. The project initializer copies and embeds it by default, with `filmConfig.channelLogoAsset` recording the chosen ID. Show the selected channel logo beside the final subscribe prompt throughout the closing CTA. Keep it clear of subtitles, preserve proportions and alpha, and use restrained wrapper motion.

Use the user's actual channel logo when provided, replacing the sample role.
